# 4A · A. Watermelon

[Original problem](https://codeforces.com/problemset/problem/4/A)

A. Watermelon

Local summary of the official problem, not the original statement.

Time limit: 1 second. Memory limit: 64 MB.

A watermelon weighs w kilograms. Decide whether it can be split into exactly two pieces, each having a positive even integer weight. The pieces need not have the same weight.

**Input:** One integer w, between 1 and 100 inclusive.

**Output:** Write YES if such a split exists; otherwise write NO.

Example: a weight of 8 can be split into weights 2 and 6.

8

YES
